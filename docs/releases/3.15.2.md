# borgmcp 3.15.2

- Reports a stale local server runtime lock with the exact `borg-mcp-server recover-stale-lock` recovery command before suggesting an update retry.
- Prevents `borg launch-all` from starting any agent sessions until the configured pinned local or LAN authority is ready, avoiding partial fleet launches during server startup.
- Limits generated agent bootstrap recovery to one attempt, then escalates to the operator while forbidding agent-driven server lifecycle actions.
