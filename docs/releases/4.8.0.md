# borgmcp 4.8.0

- Adds mechanical Git provenance to `borg_log`. Pass up to eight local Git refs through `refs`; the client resolves and appends each commit SHA before posting, and `REVIEW-READY` messages now require refs.

- Refuses invalid refs and typed full SHAs whose seven-character prefix resolves to a different local commit. Full SHAs that cannot be verified locally remain available for cross-repository citations and are identified in the tool result.

- Repairs the installed-server release exercise after `borgmcp-server` 3.3.0 removed `operatorPrincipal`; the document journey now seeds the production client-principal authorization path (#548).
