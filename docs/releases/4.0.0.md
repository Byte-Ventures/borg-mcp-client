# borgmcp 4.0.0

- Requires every `borg_log` call to choose an explicit audience with `to: "broadcast"` or a non-empty selector array. Message text and taxonomy classes no longer select recipients, and the legacy append `visibility` input is removed.
- Adds cursorless `borg_read-entry` lookup by canonical UUID or unique 8-hex prefix, with typed not-found and ambiguous-prefix refusals and no unread-cursor mutation.
- Shows resolved direct recipients in log output while preserving the cube as the read trust boundary; direct addressing controls delivery and wakes, not confidentiality.
- Makes message taxonomies classification/lifecycle-only by removing `routing` and `default_to` from their public contract.
- Updates the exact client pairing to `borgmcp-shared@1.0.0`, `borgmcp-server@1.0.0`, and protocol v12.
