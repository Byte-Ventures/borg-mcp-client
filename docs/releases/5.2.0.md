# borgmcp 5.2.0

- Adds Durable layers guidance to the regen playbook so durable rules are stored in the correct source of truth and cleaned up in the required order when a layer reaches its cap.

- Updates the exact `borgmcp-shared` dependency pin to 2.1.0 for the shared decision contract.
