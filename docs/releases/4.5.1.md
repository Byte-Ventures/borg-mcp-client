# borgmcp 4.5.1

- Withdraws the clone-family warning introduced in 4.5.0 because it also fired on the documented workflow of adding a second repository to an existing cube. Assimilation no longer reads or persists clone-family metadata for this warning, and the warning will return only after it can be scoped correctly per repository. Seat records written by 4.5.0 with the retired metadata remain readable (#263).
