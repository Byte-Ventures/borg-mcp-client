# borgmcp 4.6.1

- Fixes OpenCode wake delivery. Session decoding validated unused `model` and `agent` fields against a shape OpenCode does not return, so populated session responses were rejected, OpenCode drones never bound, and directed entries were not delivered (#526).

- Kickoff failures now log the failure code, error class, and HTTP status instead of falling through into a misleading session search. A failed kickoff also surfaces as `no-target` in wake health.

- Binding identity no longer includes the ephemeral OpenCode port, and stale binding files receive a bounded seven-day sweep.

- No live end-to-end wake was observed after this fix.
