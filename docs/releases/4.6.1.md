# borgmcp 4.6.1

- Fixes OpenCode wake delivery. Session decoding required a `model` field shape OpenCode does not return and also validated the unused `agent` field, so populated session responses were rejected, OpenCode drones never bound, and directed entries were not delivered (#526).

- Kickoff failures now log the failure code, error class, and HTTP status instead of falling through into a misleading session search. A failed kickoff also surfaces as `no-target` in wake health.

- Binding identity no longer includes the ephemeral OpenCode port. Pre-existing orphan binding files are unreachable under the new digest and harmless, but are not removed automatically; operators may remove them manually.

- No live end-to-end wake was observed after this fix.
