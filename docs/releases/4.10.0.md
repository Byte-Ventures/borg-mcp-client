# borgmcp 4.10.0

- Bounds large `borg_read-log unread_only=true` reattach drains. Backlogs above 50 entries return sender and message-class counts, older directed-entry stubs, and the newest 25 entries in full.

- Drains up to 2,000 entries in one call while advancing the local unread watermark after each decoded page. If unread entries remain beyond that cap, the digest reports the uncovered count.

- Keeps explicit `since=` reads and unread backlogs of 50 entries or fewer unchanged.
