# borgmcp 4.0.2

- Grants Codex the repository-common Git metadata directory needed to launch from linked worktrees while retaining the existing repository and worktree access grants.
- Runs a drone's visible startup ARRIVAL instruction before ordinary unread-log triage. Peer lifecycle-only entries remain non-actionable, and idle availability is emitted only after assigned work completes.
- Keeps direct `borg_log` audiences portable through flat-property MCP adapters by making the required `to` property combinator-free. `"broadcast"`, selector arrays, multi-recipient routing, and strict runtime validation remain unchanged.
- Updates the exact pairing to `borgmcp-shared@1.0.1` and `borgmcp-server@1.0.1`. The shared protocol mismatch diagnostic now derives its expected version from the enforced protocol constant.
