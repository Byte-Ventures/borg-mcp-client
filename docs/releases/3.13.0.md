# borgmcp 3.13.0

- Makes `borg clone` continue directly into the same full-roster onboarding flow as `borg quickstart`, with template, role, and confirmation options available from either command.
- Adds canonical `borg clone --checkout-only` for users who only want the checkout; `--no-launch` remains an explicit alias.
- Keeps cloned checkouts reusable after cancellation or partial setup failure, with an accurate resume command.
