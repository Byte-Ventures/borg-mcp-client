# borgmcp 5.0.0

- Adopts `borgmcp-shared@2.0.0` and protocol tag 14. This breaking protocol update requires `borgmcp-server` 4.0.0; mismatched client and server releases fail closed with update guidance.

- Removes the unused `claims` collection from the read-log wire contract. User-facing `borg_read-log` output is unchanged because the client did not expose that field.

- Keeps claim visibility on `borg_ack-status`, roster claim counts, and diagnostics.
