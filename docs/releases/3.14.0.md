# borgmcp 3.14.0

- Adds `borg server service install [--json]` as a thin facade to the verified `borgmcp-server` executable for a loopback-only per-user service that continues after the terminal closes.
- Removes the public `borg server stop` command; foreground servers stop with Ctrl-C, while managed-service stop and removal remain server-owned and are not exposed by this client.
- Adds `borg server service` namespace help that names the supported `install` command while keeping service definitions, validation, startup, replacement, and rollback owned by the server.
