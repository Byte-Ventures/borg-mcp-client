# borgmcp 4.9.0

- Adopts `borgmcp-shared@1.2.0` and requires `borgmcp-server` 3.4.0 or later.

- Matches accessible repository cubes by case-insensitive name while preserving stored casing. A single match can be adopted with explicit interactive confirmation; multiple accessible matches still fail closed.

- Reconciles built-in template roles by case-insensitive name, so an existing role such as `builder` is treated as the template's `Builder` instead of prompting a duplicate creation.

- Documents the server's role-name contract on the create-role and update-role tools: 1-64 bytes, starting with an ASCII letter or digit, with remaining characters limited to ASCII letters, digits, spaces, periods, underscores, and hyphens.

- Operator sequence: after `borgmcp` 4.9.0 is published, install `borgmcp-server` 3.4.0 and restart the live server so migration 29 applies. Report a collision refusal and never bypass it. Then update Borg installs to 4.9.0.
