# borgmcp 4.2.0

- Directed sends now work through the direct `borg_log` tool on every supported host. Hosts normalize the manifest's deliberately type-less `to` property to a string and deliver a directed recipient array JSON-encoded; the audience boundary now decodes exactly that shape before the existing selector validation. Every invalid-audience refusal is unchanged, and the `borg_tool` dispatcher path behaves as before.
- Every `borg_*` tool now carries an explicit structured-output classification. 39 tools declare an `outputSchema` and return machine-readable `structuredContent` alongside their unchanged human-readable text — machine-state queries and discovery, mutation receipts with stable identifiers, and context/domain results. `borg_tool` passes the selected inner tool's complete result through, `borg_playbook` remains text-only prose, and `borg_describe-tool` now includes the described tool's `outputSchema`.
