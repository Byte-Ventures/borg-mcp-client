# borgmcp 3.15.0

- Adds `borg server service uninstall [--json]` as a thin facade to the verified `borg-mcp-server` executable, preserving server-owned output and exit status.
- Makes managed-service install and uninstall discoverable through `borg server` help while continuing to reject stop, remove, and top-level uninstall aliases.
- Documents that uninstall preserves local server state and routes stop-without-removal to the exact macOS and Linux platform service-manager commands; neither the client nor server adds a stop command.
